# Domain docs

This is a single-context repository.

Before exploring an area, read the relevant material when it exists:

- `CONTEXT.md` at the repository root.
- Relevant decisions under `docs/adr/`.

If these files do not exist, proceed without calling attention to their absence. Create them only when domain terms or decisions need to be recorded.

Use the vocabulary defined in `CONTEXT.md` when naming domain concepts. If a proposed change conflicts with an existing ADR, identify the conflict explicitly.

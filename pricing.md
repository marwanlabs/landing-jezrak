At **5 EGP/order**, the subscription crossover is roughly **300 orders/month**:

100 orders → 500 EGP
200 orders → 1,000 EGP
300 orders → 1,500 EGP

That is exactly where you want the economics to start nudging a merchant toward Grow.

And the PAYG price is a **platform usage fee**, not a percentage of GMV. A 100 EGP order and a 10,000 EGP order both cost the merchant 5 EGP.

## Seed add-ons

I would keep these very simple rather than selling individual features.

| Seed module            | Suggested price | Includes                                                    |
| ---------------------- | --------------: | ----------------------------------------------------------- |
| **POS**                |  **299 EGP/mo** | POS, register, shifts, receipts, payment recording          |
| **Purchasing**         |  **249 EGP/mo** | Suppliers, POs, receiving, PO-product workflows             |
| **Advanced Inventory** |  **249 EGP/mo** | BOM, assembly, advanced inventory reporting                 |
| **Finance**            |  **299 EGP/mo** | Expenses, assets, accounts, statements, accounting          |
| **Growth Tools**       |  **199 EGP/mo** | Loyalty, push, broadcasts, advanced customer tools          |
| **Advanced Analytics** |  **199 EGP/mo** | Customer, product, geography, category and refund analytics |

There's an intentional pricing mechanism here.

A Seed merchant using:

**POS + Purchasing + Advanced Inventory + Finance**

would pay:

**1,096 EGP/month + 5 EGP/order.**

At only 100 orders:

**1,596 EGP/month.**

Grow is **1,499 EGP/month** and gives them all of that, more staff and more Locations.

So Jizrak can literally tell them:

> **You've outgrown Seed. Switching to Grow will save you money.**

That's exactly the upgrade behavior I'd want.

### Naming

My favorite final set is:

**🌱 Seed — Start selling**
**🌿 Grow — Run your business**
**🌳 Canopy — Run your organization**

I prefer **Canopy** over “Scale” because it gives Jizrak a distinctive naming system. Internally, you can still think of them as Starter / Growth / Scale.

The main things I'd review carefully before locking this are **5 EGP/order**, **1,499 EGP Grow**, **3,499 EGP Canopy**, and whether **Grow should remain one Store or include two**. Everything else can then be tuned around those four decisions.
